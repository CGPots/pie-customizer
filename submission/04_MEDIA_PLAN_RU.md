# Материалы для страницы

## Обязательный главный кадр

Формат: горизонтальный скриншот без браузера и личных данных.

Показать:

- чистый 3D View;
- открытое пользовательское pie menu;
- понятные команды с иконками;
- вложенное меню рядом с одним из секторов.

Лучший сюжет: меню моделирования на кубе или простой стилизованной модели.
В кадре должно быть сразу понятно, что это настоящее круговое меню Blender, а
не только окно настроек.

## Второй кадр

Показать редактор расширения:

- список из двух меню;
- выбранное сочетание клавиш;
- заполненную схему из восьми направлений;
- поиск по команде `Orientation: Local`;
- кнопку `Parameters` только у действия с доступными настройками.

## Третий кадр

Показать каталог:

- раздел `Sculpting` или `Painting`;
- несколько встроенных кистей;
- вкладки `Search` и `Sections`;
- избранное у одной команды.

## Дополнительный кадр

Показать перенос настроек:

- блок `Advanced`;
- кнопки `Import` и `Export`.

## Короткое видео

Рекомендуемая длина: 20-30 секунд.

1. Открыть готовое меню в 3D View.
2. Создать новое пустое меню.
3. Выбрать сектор.
4. Найти `Orientation: Local`.
5. Назначить сочетание клавиш.
6. Нажать `Apply`.
7. Открыть новое меню.
8. Показать вложенный список.

Для страницы лучше использовать несколько лёгких изображений и короткое видео,
а не тяжёлый GIF.

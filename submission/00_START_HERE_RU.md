# Pie Customizer 1.0.1: комплект для публикации

## Что загружать на Blender Extensions

Загрузите только этот файл:

`pie_customizer_extension_v1.0.1.zip`

Это официальный Blender Extension-пакет для Blender 4.2 и новее. Не
распаковывайте и не изменяйте его перед загрузкой.

Остальные файлы в комплекте предназначены для автора и модерации:

- `01_LISTING_EN.md` - готовый английский текст страницы.
- `02_LISTING_RU.md` - русская версия описания.
- `03_PUBLISHING_CHECKLIST_RU.md` - точный порядок публикации.
- `04_MEDIA_PLAN_RU.md` - какие изображения подготовить.
- `BLENDER_VERSION_AUDIT.md` - технический отчёт по версиям Blender.
- `SHA256SUMS.txt` - контрольные суммы архивов.

## Коротко

- Название: `Pie Customizer`
- Версия: `1.0.1`
- Автор: `cgPots`
- Совместимость: `Blender 4.2 LTS and newer`

- Цена на Blender Extensions: бесплатно
- Доступ к сети: не требуется
- Доступ к файлам: импорт и экспорт JSON-пресетов

Официальный каталог Blender Extensions принимает только свободные и
GPL-совместимые расширения. Платную версию позже можно отдельно разместить на
другой площадке, но загружаемый сюда пакет должен оставаться свободным.
